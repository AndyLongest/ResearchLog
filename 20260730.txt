Q : Alpha2 中的 null market hypothesis 是否有效？因为之前试图设计一个收益率的时序预测模型，跑不过 zero-baseline，产生了真实市场收益是不是条件均值就是0的疑惑。
A : 真实市场收益的条件均值肯定不是零，是零就不用投资了。
	还知道了收益( Return ) = 无风险收益 + 系统性风险补偿( Beta ) + Alpha + 随机噪声 , where 
		无风险收益：比如国债收益。e.g. 存银行获得时间价值补偿。
		Beta / Factor exposure（系统性风险补偿）：承担市场、规模、价值、动量、流动性等风险得到的补偿。例如买股票赚的钱，其中一部分只是承担股票市场风险。
		Alpha ：无法被已知风险因子解释的超额收益，也就是通常说的“真正的主动能力/发现”。
		噪声 ：随机波动。
	所以，一个策略赚钱，有可能是真 Alpha ，也有可能只是 Beta 没建模好。
	Beta 建模有很多方法，不同方法会得到不同 Alpha。
	所以，大型量化机构会有风险模型团队、alpha 研究团队和组合团队。
E : 添加一个实验，人造一个有 Beta ，有正收益但是没有 Alpha 的市场，看看不同方法的认证效果，Alpha2 的 method 能不能认证alpha / beta？
	我意识到这是一个很蠢的实验，没什么意义，因为 beta 指能被风险模型解释的收益，循环论证了，没什么意义的实验。

Q : 风险模型有哪些
A : R_i 第 i 个收益 ; R_f 无风险收益 ; R_m 市场收益
	1) CAPM(资本资产定价模型) : R_i - R_f = β_i * (R_m - R_f) + α_i + ε_i
	2) Fama-French 三因子模型(FF3) : R_i - R_f = β_m * MKT + β_s * SMB +β_v * HML +α_i + ε_i
	3) Carhart 四因子模型，在2）加一个MOM
	4) Fama-French 三因子模型 : 再2）加RMW CMA
	5) APT : 线性组合

不过以往alpha mining 工作并不会把“发现 alpha”和“识别 beta”作为主要问题。有一个金融学上的简化：只要这个收益不是简单的市场暴露，就叫 alpha。
