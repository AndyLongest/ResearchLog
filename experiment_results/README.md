# 实验结果记录规范

每个日期目录中的 `README.md` 使用以下格式。表格只填写实际运行结果；没有运行、不可计算或协议不兼容时，明确写出，不补造数值。

```markdown
## 实验名：<名称>

- 日期：YYYY-MM-DD
- 实现标签：paper-exact / paper-aligned / operationalized / native / controlled-style
- 协议与样本：<数据、市场、时间段、种子、重复数>
- 数值来源：<同目录文件>

### 实验数据表格

| 指标 | 设置 A | 设置 B | 备注 |
|---|---:|---:|---|
| ... | ... | ... | ... |

### 实验结论

<只写数值直接支持的结论；同时写明不能推出什么。>
```

## 记录原则

- 保留未经筛选的正式指标及区间估计。
- `native`、`paper-aligned`、`operationalized` 和 `proxy` 不混写。
- 真实市场结果不用于宣称假阳性率。
- 负收益或负 Sharpe 不描述为盈利。
- 进行中的实验与正式完成结果分开记录。
