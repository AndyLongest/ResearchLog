# Semantic-measurement prompt pilot v1 - semantic arm

Truth label: **exploratory retrospective semantic-prompt pilot - semantic-measurement arm**.

- Upstream proposer: GPT-5.4 through the existing Alpha2 adapter.
- Prompt treatment: before parameter edits, reconsider the measurement object;
  record the phenomenon, measurement object, and persistence hypothesis; use
  only the supplied DSL and do not invent unavailable intraday inputs.
- Scope: five fresh proposer seeds, CSI 500, CSI 1000, and S&P 500, origin 4,
  evidence-credit mode, and 250 candidates per run.
- All data, model settings, candidate generation, skill feedback, evidence gate,
  portfolio rules, seeds, and compute budgets are paired with the baseline arm.
- The 2023--2025 locked outcomes were already open before this pilot. Results
  are exploratory retrospective evidence, not prospective confirmation.
- The 26-feature daily typed basis cannot express genuine intraday event-arrival,
  order-book, or recovery-path measurements.
- Claude Sonnet 4.6 was attempted only at smoke level and returned
  `model_not_supported`; it was not replaced with another model.

The full remote archive retains daily evidence ledgers. The locally recovered
analysis package may exclude those large ledgers while retaining their remote
archive location and hash.
