# Semantic-measurement prompt pilot v1

Truth label: **exploratory retrospective semantic-prompt pilot**.

- Complete paired GPT-5.4 units: 15.
- Primary endpoint: locked RankIC, semantic-measurement prompt minus baseline prompt.
- Primary conclusion: **inconclusive**.
- Effect: 0.005717; 95% paired t interval [-0.014883, 0.026317].
- Claude Sonnet 4.6 is non-computable because the configured provider returned `model_not_supported`; it was not replaced with another model.
- The existing daily typed basis cannot express true intraday event arrival, order-book, or recovery measurements. The experiment tests semantic selection over the existing basis only.
- The locked period had already been opened, so this result cannot be called prospective confirmation.
