# ResearchLog

个人研究日志与实验结果归档。

## 目录

- `logs/`：按日期保存手写研究记录。原始文字原则上不改写。
- `experiment_results/`：按日期保存实验数值、结果表、结论与来源文件。

## 命名规则

- 日志：`logs/YYYY-MM-DD.txt`
- 实验：`experiment_results/YYYY-MM-DD/README.md`
- 原始或汇总数值：放在该日期目录下按实验命名的子目录中。

## 实验记录格式

每项实验固定包含：

1. **实验名**
2. **实验数据表格**
3. **实验结论**

同时保留 truth label、协议差异、缺失项与原始数值文件，避免把不兼容的结果写成可直接横向比较。
